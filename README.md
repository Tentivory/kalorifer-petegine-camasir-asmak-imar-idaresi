# Kalorifer Peteğine Çamaşır Asmak İmar İdaresi

**ISO-YOK-19.C** belgelidir. Belge yoktur. Belge olmaması belge sayılır.

Bu idare, kışın kalorifer peteğine asılan çorap, havlu ve "bir gece durur" denilen tişörtü **ruhsatsız yapı**, peteği **imar adası**, ısıyı **altyapı**, buruşukluğu **cephe ihlali** kabul eder.

## Yasal dayanak (uydurma)

- 3194 sayılı İmar Kanunu madde ∞: “Islak çamaşır, ısıtıcı yüzeye temas ettiğinde kat irtifakı doğar.”
- Buhar Yönetmeliği 7/k: “Komşu dairenin camına giden buhar, sınır aşan yayındır.”
- Peteğe Asma Genelgesi 2026/09: “Tek çorap asmak, tek taraflı ilhaktır.”

## Kuruluş

```bash
python3 idare.py
```

İsteğe bağlı argümanlar:

```bash
python3 idare.py --esya corap --adet 3 --islaklik 87
python3 idare.py --esya havlu --adet 1 --islaklik 12
```

Program:
1. Başvuruyu kaydeder.
2. İmar puanı hesaplar.
3. Yıkım, para cezası veya “ısının millete ait olduğu” kararından birini verir.
4. Tapu senedi basar (ekrana).

## Örnek çıktı

Program çalıştığında resmi evrak diliyle karar üretir. Kararlar bağlayıcı değildir. Bağlayıcı olmaması da bağlayıcıdır.
